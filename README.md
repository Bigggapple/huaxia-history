# 华夏长卷 · Huaxia History

An interactive Chinese history website featuring dynasty timelines, 280 historical figures, territorial maps, and classical literature.

## Deployment

Static HTML, CSS and JavaScript. GitHub Pages publishes from the main branch root. No dependencies or build step required.

## Local preview

Run `python3 -m http.server 8080` and visit http://localhost:8080.

## Sources

Historical profiles include source links. AI artistic interpretations are explicitly labeled. Early dates and traditional accounts may be uncertain. Third-party images retain the rights and licenses stated by their original sources.
